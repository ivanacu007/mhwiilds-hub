# Iconos de monstruos

La app busca aquí `<id>.webp` (también acepta `.png`, `.jpg` y `.avif`).
Si el archivo no existe, dibuja un icono propio generado a partir de la especie.

## Cómo poner los tuyos

Deja los archivos descargados en una carpeta cualquiera y corre:

```bash
npm run iconos:importar -- ~/Descargas/iconos
```

El importador los renombra solo. Reconoce el nombre del wiki tal cual
(`MHWA-Arkveld Icon.webp`), el nombre en inglés (`Arkveld.png`) o el nombre en
español (`Rey Dau.webp`). Los que no reconozca te los lista al final.

Esta carpeta está en `.gitignore`: las imágenes no se suben al repo.
